# Image Prompts — Platzidle Launch Campaign

Three prompts. **Each starts with the same STYLE BLOCK** so the images read as one campaign even when generated separately.

> **Text-rendering tip:** most image generators render long text poorly. Use a text-strong model (GPT-4o / DALL·E 3 / Ideogram) for these, OR generate the visuals without the small text and add the wordmark, tagline and course labels afterward in Canva/Figma using **DM Sans**. Keep the exact colors below.

---

## STYLE BLOCK (paste at the top of every prompt)

```
Style: clean flat-vector UI illustration, modern, techy and friendly — NOT photorealistic, no stock-photo people, no clutter. Poster-like, centered, high contrast, generous negative space.
Background: deep navy #0c1420. Cards/panels: #121d2b with subtle rounded corners.
Signature motif: a Wordle-style grid of square letter tiles.
Tile colors: solved/correct tiles = Platzi green #0bd982 with DARK #0c1420 letters for contrast; "present" tiles = amber #c9a227; "absent" tiles = slate #38465a; text on dark background = off-white #e8eef5.
Typography: bold geometric sans-serif (DM Sans style). Wordmark reads "Platzidle" — "Platzi" in off-white, "dle" in Platzi green #0bd982.
Accent: a soft green glow around the solved green tiles.
```

---

## Prompt 1 — HERO (main image) · aspect ratio 1:1 (also render 4:5)

```
[STYLE BLOCK]
Scene: a Platzidle game board, 6 columns wide and a few rows tall, centered. The winning row spells "DOCKER" in solved Platzi-green tiles (#0bd982) with dark letters; the rows above are faint empty tiles with thin outlines. Directly below the board, a result card (#121d2b) that reads "Learn more: Curso de Docker" with a small green arrow/button and a subtle Platzi mark, clearly linking out. At the top, the "Platzidle" wordmark. At the bottom, the tagline in clean DM Sans: "Learn tech by playing — one term a day, one course a click away." Balanced, poster-like, lots of dark space.
```
Notes: This is the single most important asset — it must show the game AND the payoff (solved word → real course) at a glance.

## Prompt 2 — PAYOFF (solve → real course) · aspect ratio 1:1 (or 4:5)

```
[STYLE BLOCK]
Scene: a two-step "before → after" composition connected by a bold green arrow (#0bd982). STEP 1 (left/top): a smartphone screen showing the Platzidle board with "DOCKER" solved in green tiles. STEP 2 (right/bottom): the real Platzi course card titled "Curso de Docker" — a course thumbnail with a play button and Platzi branding, looking like an actual course page. Small caption in DM Sans between them: "Solve it → tap → you're in the real Platzi course." Keep both screens on the deep-navy background so they feel like one system.
```
Notes: This piece exists to hammer the differentiator. The arrow + two screens = the whole idea in one glance.

## Prompt 3 — EXAMPLES ("a new term every day") · aspect ratio 1:1

```
[STYLE BLOCK]
Scene: three small Platzidle boards arranged in a neat row (or 2+1 grid), each solving a different tech term in Platzi-green tiles: "PYTHON", "KUBERNETES", "TOKEN". Under each board, a small course label in DM Sans with a green arrow: "→ Curso de Python", "→ Curso de Kubernetes", "→ Curso de Node.js". A short bold headline across the top: "A new term every day." Consistent spacing, same tile style and glow on all three.
```
Notes: Real term→course mappings (from reto-08): PYTHON→Curso de Python · KUBERNETES→Curso de Kubernetes · TOKEN→Curso de Node.js: Autenticación, Microservicios y Redis (shorten to "Curso de Node.js" on the image for space).

## Consistency checklist (before publishing)

- [ ] Same deep-navy background `#0c1420` in all three.
- [ ] Solved tiles are Platzi green `#0bd982` with dark letters everywhere.
- [ ] "Platzidle" wordmark styled the same ("dle" in green).
- [ ] DM Sans (or close) used for all text.
- [ ] Each image lands the payoff (game → real Platzi course).
- [ ] Real terms + real course names only.
